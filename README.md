# tmp_ac26

Тимчасове демо адвент-календаря «23 пари»: статична сторінка, відкривається з `index.html`.

- Щоб побачити календар станом на певний день грудня, додайте до адреси `?day=5`.
- Мова перемикається кнопками «Укр / Eng» у верхній стрічці або параметром `?lang=en`.

A temporary demo of the “23 pairs” advent calendar: a static page served from `index.html`.
Add `?day=5` to the address to preview a given day of December, and `?lang=en` for English.
